# Logo Videos Directory

This directory stores video assets, animated bumpers, and motion graphic intros for the Building Management System.

## Contents & Formats

- **`animated_logo_intro.html`**: Interactive HTML5 / Canvas 60 FPS video renderer with real-time video export (`.webm` / `.mp4`).
- Supported file types for drop-in motion graphics:
  - `.mp4` (H.264 / AAC)
  - `.webm` (VP9 / Opus)
  - `.mov` (ProRes with Alpha / Transparency)
  - `.json` (Lottie / After Effects animations)
